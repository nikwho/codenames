# Codenames Realtime MVP

Браузерная real-time игра по механике «Кодовые имена».

Для продолжения разработки в другой сессии / ОС см. [`HANDOFF.md`](HANDOFF.md) (архитектура, актуальные правила, что уже сделано).

## Стек

- TypeScript
- Frontend: React + Vite + Tailwind
- Backend: Node.js + Express + Socket.IO
- Хранение комнат: in-memory
- Идентификация устройства: `localStorage` `deviceId`

## Установка

```bash
npm install
```

## Запуск локально

Запустить сервер и клиент вместе:

```bash
npm run dev
```

Или отдельно:

```bash
npm run dev:server
npm run dev:client
```

По умолчанию:

- клиент: `http://localhost:5173`
- сервер: `http://localhost:3001`
- health check: `http://localhost:3001/api/health`

Если сервер запущен на другом адресе, передайте клиенту переменную:

```bash
VITE_SERVER_URL=http://localhost:3001 npm run dev:client
```

## Как проверить MVP

1. Откройте `http://localhost:5173`.
2. Создайте комнату как отгадывающий.
3. Первая вкладка станет базовым устройством “Стол”.
4. Откройте ссылку комнаты во второй вкладке или на другом устройстве.
5. Во второй вкладке выберите роль и команду.
6. Добавьте загадывающего в отдельной вкладке или смените роль на “Загадывающий”.
7. На устройстве “Стол” нажмите “Старт игры”.
8. В фазе подсказки загадывающий отправляет слово и число.
9. В фазе отгадывания удерживайте карточку 2 секунды, чтобы открыть ее.
10. Проверьте, что раскрытие и таймер синхронизируются между вкладками.

## Структура

```text
shared/  # общие типы и Socket.IO контракты
server/  # Express + Socket.IO + game engine + таймеры + тесты
client/  # React + Vite + Tailwind UI
```

## Игровые роли

- Первый отгадывающий автоматически становится “Столом”.
- “Стол” может открывать карточки за активную команду и управлять игрой.
- Обычные отгадывающие выбирают `red` или `blue`.
- Один загадывающий может давать подсказки за обе команды.
- Второй загадывающий выбирает команду, первый автоматически закрепляется за противоположной.
- Наблюдатели только смотрят.
