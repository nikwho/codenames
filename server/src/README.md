# Русский словарь Codenames

Готовая замена прежних `words.ru*.ts`.

## Состав

| Набор | Слов | Использование |
|---|---:|---|
| `easy` | 846 | Простые и наглядные слова |
| `standard` | 980 | Добавляется к easy; это обычный режим |
| `advanced` | 892 | Абстрактные, длинные и специализированные слова |
| `adult` | 37 | Грубая лексика, алкоголь, сексуальные и тяжелые темы |
| `military` | 45 | Военная тема, уже заметно прореженная |
| `politics` | 44 | Политика |
| `religion` | 32 | Религия |
| `soviet` | 8 | Советская тематика |
| `nationalities` | 19 | Национальности |

Обычный `WORDS_RU` содержит **1826 слов** (`easy + standard`).
Полный словарь содержит **2903 слова**.

Из исходных 3177 слов удалено **620**:
- канцелярских, процессных и слишком общих — 445;
- близких дублей и вариантов формы — 82;
- редких, неудачных и контекстно неполных — 68;
- избыточных военных терминов — 25.

Добавлено **346 новых слов**. Все они уже распределены по наборам.

## Быстрая интеграция

Замените старые файлы содержимым этой папки. Старый вызов продолжит работать:

```ts
import { WORDS_RU, pickWords } from "./words.ru.js";

const words = pickWords(25);
```

По умолчанию:
- используется `easy + standard`;
- взрослый и тематические наборы отключены;
- близкие пары не попадают на одно поле;
- перемешивание выполняется Fisher–Yates.

## Другие режимы

```ts
pickWords(25, { difficulty: "easy" });

pickWords(25, { difficulty: "advanced" });

pickWords(25, {
  difficulty: "standard",
  themes: ["military", "religion"],
});

pickWords(25, {
  difficulty: "advanced",
  includeAdult: true,
});

pickWords(25, {
  avoidClosePairs: false,
});
```

## Файлы

- `words.ru.ts` — публичный API и генератор;
- `words.ru.easy.ts` — easy;
- `words.ru.standard.ts` — standard;
- `words.ru.advanced.ts` — advanced;
- `words.ru.adult.ts` — adult;
- `words.ru.themed.ts` — тематические наборы;
- `words.ru.conflicts.ts` — 119 групп близких слов;
- `words.ru.audit.json` — полный отчёт об удалениях и добавлениях.

`негр` удалён полностью и отсутствует во всех наборах.
